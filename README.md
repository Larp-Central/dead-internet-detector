# D.i.D — Dead Internet Detector

Engagement authenticity intelligence.

D.i.D analyzes online engagement for patterns associated with synthetic, coordinated, or abnormal activity.

## MVP

- YouTube video scanning
- Humanity Score
- Comment repetition analysis
- Timing burst detection
- Conversation depth
- Language diversity
- Explainable anomaly reports

## Roadmap

- Semantic duplicate detection
- Account coordination clustering
- Creator comparisons
- Twitch / YouTube Live monitoring
- Agency API

## How it works

1. Ingest public engagement data
2. Extract behavioral signals
3. Detect similarity, timing, and coordination patterns
4. Calculate risk and confidence scores
5. Explain the evidence behind each result
